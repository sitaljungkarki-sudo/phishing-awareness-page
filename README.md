# Phishing Awareness Page

An educational phishing simulation project built to teach users how to identify phishing attacks.

## About This Project

This project simulates a fake login page that, instead of stealing credentials, redirects users to an awareness page explaining exactly what happened and how to spot real phishing attempts.

**Built by:** sitaljungkarki-sudo  
**Purpose:** Educational — Cybersecurity Awareness

## What It Demonstrates

- How phishing login pages are designed to deceive
- Common red flags users should watch for
- Ethical use of security knowledge for education

## Red Flags Covered

1. Suspicious / unverified URLs
2. Urgency language and pressure tactics
3. Generic or lookalike branding
4. Missing HTTPS / padlock
5. Unsolicited login requests

## Disclaimer

This project is strictly for **educational purposes**. No user data is collected, stored, or transmitted at any point. This simulation exists to raise cybersecurity awareness.

## Tech Stack

- HTML5
- CSS3
- No backend — fully static and safe
